# 能源局许可查询器

国家能源局资质和信用信息系统 — 许可公示查询工具，支持批量关键词查询、断点续采、导出 Excel。

## 安装

```bash
pip install gmssl requests PyQt5 openpyxl
```

## CLI 模式

命令行直接查询并导出，无需打开界面。

### 基本用法

```bash
python app.py 广州
python app.py 广州 深圳 珠海
```

### 输出结构

```
export_20260730_223000/
├── 合并_20260730_223000.xlsx    # 所有关键词合并
└── 分文件/
    ├── 广州_20260730_223000.xlsx
    ├── 深圳_20260730_223000.xlsx
    └── 珠海_20260730_223000.xlsx
```

### 数据字段

| 字段 | 说明 |
|------|------|
| 企业名称 | 公司全称 |
| 申请人名称 | 许可申请人 |
| 许可证书状态 | 正常/注销/(null) |
| 统一社会信用代码 | 18位信用代码 |
| 许可证类别 | 发电/输电/供电/承装(修、试) |
| 承装等级/承修等级/承试等级 | 仅类别为4时显示 |
| 许可证编号 | 许可证唯一编号 |
| 许可证核发日期 | 颁发日期 |
| 有效起始日期 | 有效期开始 |
| 有效到期日期 | 有效期结束 |
| 许可证核发机关 | 颁发机构 |

## 界面模式

双击运行或不带参数启动：

```bash
python app.py
```

### 操作流程

1. 输入关键词后回车添加，支持批量输入（空格/逗号/顿号分隔）
2. 点击 **采集** 开始查询
3. 采集完毕点击 **批量导出**
4. 选择导出方式：合并为一个文件 / 分文件导出

### 采集状态

| 状态 | 说明 |
|------|------|
| 待处理 | 等待采集 |
| 采集中 | 正在请求 |
| 采集完毕 | 查询成功 |
| 采集失败 | 出错了 |

### 操作按钮

| 按钮 | 说明 |
|------|------|
| 查看 | 预览数据 |
| 重采 | 重新查询 |
| 导出 | 导出单个关键词 |
| 删除 | 移除关键词 |

## 编码映射

`dict.json` 控制编码与中文的对应关系，可随时修改：

```json
{
  "entertype": {
    "1": "发电类企业",
    "2": "输电类企业",
    "3": "供电类企业",
    "4": "承装(修、试)类"
  },
  "licstate": {
    "1": "正常",
    "5": "注销",
    "null": "正常(null)"
  }
}
```

未知编码会保留原始值，不会丢失数据。

## 打包为 EXE

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "能源局许可查询器" --add-data "能源.svg;." app.py
```

分发文件：`能源局许可查询器.exe` + `dict.json`
